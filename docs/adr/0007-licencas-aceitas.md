# ADR-0007: Licenças de conteúdo aceitas

- **Status:** Aceita
- **Data:** 2026-10-01

## Contexto

o app é gratuito e sem anúncios; conteúdo Creative Commons exige crédito e algumas licenças proíbem modificação.

## Decisão

aceitar CC0, CC-BY, CC-BY-SA, CC-BY-NC, CC-BY-NC-SA; descartar ND; filtro configurável; crédito sempre exibido.

## Consequências

catálogo rico; se o app for monetizado, basta remover NC do filtro (menos mídia disponível).
